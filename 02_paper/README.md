## What changed in v3 (review: `REVIEW_2026-10-29.md`)

- Every number, both result tables and the two route figures are generated by `latex/make_numbers_v3.py` from the result files of the
  2 Oct re-run (ADR-017: Beta index, evidence on both directions, 1,000 pairs), the verifier evaluation, and the conformal studies
  (ADR-036). No result is typed into `paper.tex`.
- The method section describes the Beta-posterior index the router runs (ADR-015), with a monotonicity proposition and proof; the old
  Wald index becomes Observation 1, with the crossover range re-checked numerically and a worked example computed by the router's own
  code (`01_code/citypulse-IDP/packages/pulse_belief/tool/paper_example.dart`).
- Results now report the hybrid baseline beating C3 at the same risk weight, the held-out check with paired intervals (crowd evidence
  moves routes toward reported edges), calibration against the prior, and the conformal results.
- "What did not work" became "What failed, and what we changed".
- Table I updated (phone install, unmeasured; router service). Test counts removed.
- Added: data and code availability; an AI-use disclosure in the acknowledgment; the Angelopoulos and Bates conformal reference.
- The three web references were opened and added to the verified list; access dates updated.
- 30 Oct 2026: a new Section VIII on the prototype evidence dataset (CSFE v0.2, `01_code/citypulse-IDP/data/csfe/`) and its benchmark,
  with its values generated from the build's `summary.json` and the B1 result; Related Work condensed (90 → 73 references, all verified)
  to keep the length near v2's 8 pages; the datasheet reference (Gebru et al.) added and verified.

## Build

```
cd latex
python make_numbers_v3.py
python check_v3.py
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
python check_citations.py paper.tex
```

`make_numbers_v3.py` needs the project's result files and Python with matplotlib; `check_v3.py` checks macros, references, braces,
citations against the verified list and the abstract length without TeX; `check_citations.py` needs the `.bbl` from a TeX build.
